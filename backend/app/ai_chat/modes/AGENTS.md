# 内置对话规则文件

- 本目录只存四种对话方式的 Markdown 规则；标识和显示信息由同级 mode_service.py 固定登记，不支持任意路径加载。
- 文件名用英文短横线；内容变更通过代码审查发布，服务端按实际内容生成版本哈希。
- unknowns-original.md 保留用户提供的原始 Skill 作来源记录，不加载执行；unknowns.md 为明确标注的网页适配版。
- 三份 Prompt 保留原文实质要求，仅清理网页复制的 Markdown 包装与待替换占位符；用户主题由对话消息提供。
- 已发送会话保存当时的规则快照，文件更新不改变历史会话。正式规则不自动清理；临时文件不得放入本目录。
