# 方舟公海背调自动任务

每次 heartbeat 执行以下流程：

1. 使用 `$ark-public-pool-research` 以 `page_size=100` 列出可领取任务。
2. 对 T1 执行最近 60 天订单安全检查；命中时跳过，不领取、不完成、不标失败。
3. 无合格任务时回复 `HEARTBEAT_OK`。有任务时只领取第一条，每轮最多一条。
4. 读取 context 后先检索有权访问的已发布企业知识，获取目标产品、客户画像、排除规则和成交经验基准；只读有用文档，不做全库扫读。
5. 先做低成本行业门控并调用 `ark_submit_public_pool_industry_gate`。只有返回 `deep_research_authorized=true` 才进入后续步骤；无关客户由门控接口直接完成并停止，不再找联系人/社会关系，不研判供应商或深度风险，不生成触达草稿。
6. 证据不足不等于无关。无官网或官网薄弱时，重点核验 Instagram、Facebook、TikTok、LinkedIn、Google Business、预约/店铺页的身份互链、业务内容和近期活跃度。
7. 仅对核心/邻近相关客户继续重点或深度背调，输出客户类型、采购阶段、体量、正负成交信号、未知项、验证问题和未发送英文草稿。
8. 研究超过 10 分钟时在租约到期前续租。只有网络、鉴权、接口故障才标失败；身份无法确认时提交 `unverifiable`。
