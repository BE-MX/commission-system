# 部署目录约定

- 用户入口为 `deploy.bat`；Python 脚本承载可测试的构建、增量同步与云端更新逻辑，配置只放非敏感主机/目录/组件定义。
- 不迁移业务文件到 COS，不复制 `.env`、密钥、会话、uploads 或用户数据作为代码制品；文件所属实例与 Scheduler 单活位置保持明确。
- 临时制品、日志和成功标记只写仓库 `.deploy_state/`（Git 忽略）；远端 staging/release 仅限配置登记的部署目录，不扫描或删除相邻业务目录。旧资源按发布清单保留，当前任务不自动清理历史版本。
- 远端脚本输入必须校验路径和摘要；SSH 非交互，失败返回非零；未变化文件用 SHA-256 核对后跳过。成功状态只能在目标验证后写入。
- 部署测试放 `deploy/tests/`，只用临时目录/模拟进程，不连接生产数据库。基础设施模板放现有 `nginx/`、`systemd/`；其备份仅保存在对应服务器受限目录。
- 已知但不受本仓库管理的独立服务必须逐项报告真实状态，不能在没有指定新版本时拉取 latest 或假报已更新。
