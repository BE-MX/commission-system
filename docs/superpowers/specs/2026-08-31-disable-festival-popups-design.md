# 采购节看板关闭全部弹窗设计

## 目标

采购节五个轮播看板不再显示任何事件弹窗，包括个人、团队、阵营和公司主体的 L3 插播条与 L4 全屏回放。

## 实现

- 从 `zhaiyao.html`、`xinqian.html`、`fugou.html`、`zhenying.html`、`tuandui.html` 移除共享弹窗样式和脚本引用。
- 删除不再使用的 `festival-popup.js` 与 `festival-popup.css`。
- 各页面沿用现有无弹窗时的 30 秒定时跳转逻辑。
- 截图任务不再传递已失效的 `popup=0` 参数。
- 更新摘要页中已过时的弹窗说明。

## 保留范围

- 摘要页右侧“事件滚动流”继续显示。
- 后端事件检测、事件留档、接口返回和钉钉通知保持不变；只清理截图 URL 的失效参数。
- 看板取数、刷新、页面导航和 `stay=1` 固定页面能力保持不变。

## 验收标准

1. 五个看板均不加载弹窗 CSS/JS，也不创建弹窗 DOM。
2. 页面按原顺序每 30 秒轮播，`stay=1` 时不自动跳转。
3. 摘要页事件滚动流继续正常渲染。
4. 前端构建和项目约定检查通过。
