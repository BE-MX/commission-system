# 客户产品效果图外链页双语设计规格

> 日期：2026-08-26  
> 范围：公开邀请页 `/create/{token}` 与规范化后的 `/create`  
> 已确认方案：页面内独立语言字典，默认英语，可切换中文

## 1. 目标与边界

客户打开产品效果图邀请链接时，页面固定 UI 默认显示英语，并可在任何页面状态切换为中文。切换后，同一屏幕上的标题、按钮、提示、错误、状态、无障碍标签和下载文件名必须使用同一种语言，不出现中英混杂。

本次只翻译系统控制的固定 UI 文案。产品名称、产品分类、产品描述、参数名称及参数值由后台配置，继续按原值展示；本次不新增数据库字段、迁移、管理端翻译录入或 API 字段。

## 2. 方案

在 `frontend/src/views/customer-image/` 内建立该公开页面专用的轻量语言模块：

- 支持 `en`、`zh-CN` 两种语言；无有效历史偏好时使用 `en`。
- 语言选择保存到 `localStorage`，下次访问沿用；无法读取或写入存储时静默回落英语，不影响生图主流程。
- 根页面提供响应式 `locale`、`setLocale()` 和 `t(key, params)`；子组件通过同一组合式函数读取，避免逐层传递翻译函数。
- 页面挂载时同步 `<html lang>`，卸载时恢复原值，保证屏幕阅读器得到正确语言信息。
- 业务状态保存稳定的消息 key 和参数，不保存已经翻译的句子。这样客户在错误、排队或生成完成状态下切换语言时，当前消息也会立即更新。

不引入 `vue-i18n`。当前需求只覆盖一个独立公开页面，全局框架会扩大依赖、入口初始化和其他页面回归面。

## 3. 交互设计

- 语言切换器固定显示在页面右上区域，加载、失效、空数据、网络错误、产品目录和编辑工作台都能使用。
- 控件显示两个明确选项 `EN` 与 `中文`，当前项有选中状态，并提供可读的 `aria-label`、`aria-pressed`。
- 点击后文字立即替换，不做整页淡入、位移或布局动画。语言切换是高频状态操作，额外动画只会拖慢反馈。
- 保留现有按钮按压反馈；移动端保证至少 44px 点击高度，不遮挡品牌、客户名称或固定底部生成按钮。

## 4. 文案覆盖范围

必须覆盖：

- 加载、失效、空产品、通用错误与重试状态。
- 顶栏品牌副标题、专属通道和客户目录页。
- 搜索、分类、产品卡片与空搜索结果。
- 产品选择、LOGO 上传、参数、补充要求、额度、生成按钮与禁用原因。
- 排队、生成中、成功、失败、设置冲突、额度或上传错误。
- 结果预览、历史列表、下载、图片替代文本、屏幕阅读器播报。
- 下载文件名中的固定后缀；产品名称仍使用后台原值。

## 5. 数据流与异常

语言只影响展示，不进入公开 API 请求，不改变邀请令牌、产品选择、LOGO、额度、轮询、幂等请求 ID 或生成记录。Provider/API 返回的技术细节仍由现有客户安全错误映射转换为受控消息 key，再由语言字典渲染。

字典 key 缺失时开发环境应易于发现，生产展示可回落到英语文本或 key，但不得抛错阻断页面。存储中出现未知语言值时按英语处理。

## 6. 验收与验证

1. 清除语言偏好后打开邀请页，加载态和成功页面均为英语。
2. 在任一页面状态切换中文，当前全部固定文案立即变为中文；切回英语同理。
3. 刷新页面后保留用户选择；未知或损坏的偏好回落英语。
4. 后台产品名称、分类、描述、参数和值保持原样，搜索与选择仍可用。
5. 语言切换不改变请求载荷、额度、轮询、下载资源或邀请失效行为。
6. 桌面与移动端切换器不遮挡内容，键盘可操作，页面语言属性同步更新。
7. 新增语言模块与双语状态测试，现有 customer-image 测试、前端构建及约定检查全部通过。

## 7. 非目标

- 不翻译后台配置的业务内容或 AI 生成内容。
- 不改内部“客户产品效果图”管理页。
- 不自动根据浏览器语言切换；产品要求是无偏好时默认英语。
- 不增加第三种语言、远程语言包或运行时翻译服务。
