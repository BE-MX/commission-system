# 知识库编辑器 P0 增强设计

## 目标

在不改变知识库审批、权限和修订模型的前提下，把当前 Tiptap POC 提升为可供日常知识文档编写的编辑器。P0 只增强现有受控 JSON schema 能表达的内容，并补齐语雀式高频交互。

## 范围

- 顶部吸附工具栏：正文、H1-H6、粗体、斜体、删除线、行内代码、有序/无序列表、任务列表、引用、代码块、分割线、链接、表格、撤销与重做。
- `/` 命令菜单：可键盘筛选和执行上述块级命令。
- 选区浮动工具栏：粗体、斜体、删除线、行内代码和链接。
- 表格上下文操作：插入表格、增删行列、表头切换和删除表格。
- 右侧大纲：从 H1-H6 实时生成，点击滚动到对应标题。
- 保存反馈：未保存、保存中、已保存时间和保存失败；保持手动保存，不增加自动保存。
- 快捷键提示和编辑器空内容提示。

## 明确不做

- 图片、附件、颜色、高亮、字号、对齐和缩进；这些需要扩展后端 schema 或私有文件服务。
- 评论、@成员、实时协作、AI 写作、导入导出和外链分享。
- 自动保存；当前每次保存都会创建不可变 revision，直接自动保存会制造大量业务版本。

## 组件边界

- `editorConfig.js`：纯数据和纯函数，维护命令目录、标题大纲提取、保存状态文案。
- `EditorToolbar.vue`：固定工具栏及表格上下文操作，不负责保存和文档加载。
- `EditorSlashMenu.vue`：显示、筛选和执行命令；菜单定位由编辑器坐标提供。
- `EditorOutline.vue`：渲染标题树入口并触发滚动。
- `KnowledgeEditor.vue`：组合上述组件，持有 Tiptap 实例和保存状态，不继续堆叠所有按钮实现。

## 数据与安全

正文仍以 Tiptap JSON 为事实源。前端只启用后端白名单已经接受的节点和 marks；链接继续限制为 `http`、`https` 和 `mailto`。任务列表补充 Tiptap ListKit 依赖，但不改变 JSON 名称。大纲只从本地编辑器状态派生，不持久化。

## 验收

- 所有 P0 命令可通过工具栏或 `/` 菜单执行。
- 表格可完成常用结构操作。
- 大纲随标题变化并可定位。
- 保存状态覆盖脏数据、进行中、成功和失败。
- viewer 仍然只读，editor/admin 才显示编辑入口。
- 前端目标测试、构建和项目约定检查通过。
