# 企业知识库字体颜色设计

## 目标

为知识库编辑器增加受控的字体颜色能力。用户选中文字后可从工具栏快速设置颜色；只有光标时，所选颜色应用于后续输入。颜色必须服从方舟设计系统，不能把外部文档的任意色值带入企业知识库。

## 范围

本次包含：

- 工具栏增加字体颜色入口和标准色面板。
- 支持默认、重点、风险、完成、说明五种用户可见选项。
- 保存、读取、继续编辑和发布内容时保留标准颜色。
- 外部粘贴的任意字体颜色不进入文档数据。
- 后端只接受已登记的语义颜色值。

本次不包含背景高亮、字号、字体、渐变色、自定义颜色、最近使用颜色或颜色管理后台。

## 用户交互

### 工具栏入口

现有文字格式组增加一个带颜色下划线的 `A` 按钮。下划线显示当前光标位置或选区的字体颜色；没有颜色标记时显示默认正文色。

点击按钮打开紧凑色板。色板包含：

| 用户名称 | 语义值 | 设计令牌 |
| --- | --- | --- |
| 默认 | 无标记 | `--text-primary` |
| 重点 | `gold` | `--color-primary` |
| 风险 | `danger` | `--color-danger-text` |
| 完成 | `success` | `--color-success-text` |
| 说明 | `info` | `--color-info-text` |

每个选项同时显示色点和中文名称，不能只靠颜色传达含义。当前颜色显示选中态。键盘聚焦有明确轮廓，按 `Escape` 可关闭色板，点击色板外部也会关闭。

### 应用规则

- 有文本选区：颜色应用于选中文字。
- 只有光标：颜色成为后续输入的当前标记。
- 选择“默认”：移除选区或后续输入的字体颜色标记。
- 字体颜色可与加粗、斜体、删除线、行内代码和链接同时存在。
- 不增加新的键盘快捷键。
- 色板只使用现有轻量按压和聚焦反馈，不增加入场动画；`prefers-reduced-motion` 下不依赖运动表达状态。

## 文档模型

新增 Tiptap mark：

```json
{
  "type": "textColor",
  "attrs": { "tone": "gold" }
}
```

`tone` 只允许 `gold | danger | success | info`。默认正文不保存 mark。

使用语义值而不是十六进制色值有三个结果：

1. 历史文档会跟随设计令牌变化，不会固化旧色值。
2. 后端校验集合稳定且有限。
3. 外部 HTML 的 `style="color: ..."` 不会被解析为 `textColor`，粘贴时自然移除任意颜色。

前端只解析自身渲染的 `span[data-text-color]`，并将语义值映射到固定 CSS 类；不接受内联色值。

## 组件边界

- `TextColorMark.js`：定义 `textColor` mark、语义值白名单以及 HTML 解析和渲染。
- `TextColorPicker.vue`：渲染工具栏入口、色板、选中态、关闭行为和无障碍标签。
- `EditorToolbar.vue`：组合颜色选择器，不持有颜色规则。
- `KnowledgeEditor.vue`：注册 mark，并为各语义值提供设计令牌样式。
- `backend/app/knowledge/content.py`：允许 `textColor` mark，严格校验 `tone`。

颜色常量只定义一次并由颜色组件与测试复用，避免工具栏、mark 和测试各自维护不同集合。

## 数据流

1. 用户选择颜色。
2. 颜色组件调用编辑器命令设置或移除 `textColor` mark。
3. Tiptap JSON 保存语义 `tone`。
4. 后端内容校验确认 mark 类型、属性键和值均在白名单中。
5. 修订仍按现有不可变 revision 流程保存；无需数据库迁移。
6. 文档重新加载后，mark 渲染为对应设计令牌颜色。

## 错误与安全边界

- 未知 `tone`、缺失 `tone`、多余属性或非对象 attrs 均由后端拒绝。
- 现有未知 mark、脚本节点、危险链接等拒绝规则不变。
- 外部粘贴的任意 CSS 颜色不会创建 `textColor` mark，因此不会在保存阶段才突然报错。
- 前端不提供任意颜色输入框，也不把 CSS 变量名或十六进制色值写入文档。

## 测试与验收

### 后端

- 接受四种标准 `textColor` tone，并保持提取出的搜索文本不变。
- 拒绝未知 tone、缺失 tone 和多余属性。
- 知识库 API、服务和完整后端测试通过。

### 前端

- mark 只解析受控的 `data-text-color`，不解析外部内联颜色。
- 色板包含五个中文选项，默认项执行清除，其他项执行设置。
- 工具栏入口显示当前颜色并支持选区和后续输入。
- 颜色可与既有文字 mark 共存。
- 知识库前端测试和生产构建通过。
