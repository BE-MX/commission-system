# AI 接入管理配置即时生效

目标：已支持协议内，管理员通过 Provider / Preset 配置型号、调用参数，后续请求直接读取，不再改型号目录代码。

1. 生图目录从数据库预设生成；预设名作为稳定选择键，保留历史任务型号解析（仅唯一匹配）。已有 design_image_generation 前缀自动归入生图，可通过 parameters.studio.enabled 显式控制。服务端仍验证用途、启用状态、协议、认证与 HTTPS URL；不接受浏览器指定任意供应商。
2. AI 接入管理提供生图启用、名称、接口形式的配置入口；错误 JSON 阻止保存。图片扩展参数使用 request_parameters，保留请求身份、图片输入和单结果协议边界。
3. 方案对话读取实际预设型号，接受已有 OpenAI/Anthropic 流式适配器；客户生图取消固定型号。停止启动时重写已有 Provider 地址和模型。
4. 回归：新型号与供应商无需源码改动即可进入目录和任务；跨预设同型号无歧义；停用/删除/非图片用途不得调用；配置版本漂移仍拦截；参数不会覆盖业务输入；后台错误 JSON 不丢配置。
5. 运行受影响 pytest（SQLite、网络 mock）、前端回归与构建、约定检查、独立契约审查和 git 巡检；同步 API/模块/交接文档。

范围：本地实现，不修改生产配置，不调用付费生成，不自动合并、推送或部署。无表结构变化。
