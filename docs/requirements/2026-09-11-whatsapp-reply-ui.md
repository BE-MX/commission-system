# WhatsApp 1.5.3 话术面板整理

包含1.5.1能力字段修复、1.5.2历史复用。界面分为三个标签页：

- 建议回复：对客正文与中文含义直接展示；理由/依据、生成要求折叠，保留短一点/柔和一点/换策略。删除重复的“按本次目标生成”按钮，统一使用重新生成。
- 聊天上下文：读取范围、采集情况、JSON下载和数据使用说明。
- 询盘与接管：记录、承诺台账、内部接管摘要与暂停/恢复辅助。

底部固定填入、恢复原草稿、生成/取消操作；填入是有结果时的主操作。切换标签页不会修改设置或触发生成，支持左右方向键、Home/End切换；无动画。数据发送的简短说明保留在建议页。

验证：类型检查、构建、231单元测试、19合成Chromium/Lexical浏览器测试通过。覆盖窄窗口、键盘标签切换、填入/恢复、接管、JSON导出及重复生成不重滚历史。预览使用合成数据，尚未验证用户实际WhatsApp页面。

安装：替换扩展文件、重新加载，确认1.5.3，然后刷新WhatsApp页面。不需更新后端。本轮未合并推送。
