# AI 工作台第二版：实现与验收契约

范围为真实双协议联调、生成恢复、回答版本/继续生成、用量与角色额度管理。基于首版 b2970a46；实现验证完成后用户已授权提交、合并 main 和推送 origin；仍不部署或修改生产配置。

## 实现顺序

1. 新增租约、结束原因、版本选择和角色额度持久化；补断流/重启恢复与附件删除回归。
2. 同一问题的回答在原位切换版本；浏览旧版本不改变上下文，只有最后一轮允许明确采用版本。继续生成创建保留原文的新版本，原回答不被覆盖。
3. 在 AI 接入中增加聊天运行面板与角色日额度；预设可选配置每百万输入/输出 token 价格。按调用时价格和已报告用量估算，不把未知用量当作零，不合并不同币种。
4. 用现有配置进行有限真实联调，合成提示和合成图片；源库只读，供应商调用及聊天日志落在隔离环境。覆盖两种协议、多轮、截断/继续、推理、停止和图片；不把模拟异常说成真实供应商异常。

## 关键边界

- 生成线程定期续租并保存部分正文；租约过期后重新打开/发送自动标记中断，不自动重发。旧工作线程不能覆盖恢复后的终态。停止不承诺供应商即时停止计费。
- 周期 heartbeat 避免长推理期被网关当作空闲。网络线程不访问请求 Session，数据库仍串行使用。
- 原配置和账号/角色权限在每次新生成时重新验证；继续生成使用原回答所属预设并复核当前配置；已结束的旧答案保持历史标识。
- 角色额度未配置时使用系统默认；多角色使用已配置额度中的最小值，避免角色叠加绕过限制。0 表示暂停生成。管理员有配置权限，日额度不自动豁免。
- 管理面板仅返回模型/用户/用量/状态等统计，不返回会话正文。费用为配置价格下的估算，供应商实际账单为准。价格缺失或 token 不完整时明确标为未计价。

## 验收

- 隔离 SQLite 回归；真实 MySQL 迁移保留旧记录、并发配额和租约恢复的迟到写入防护。
- 请求幂等、跨用户/角色越权、选择过期版本、继续生成失败时保留原文。
- 桌面/窄屏实际组件交互；生产构建、增量约定、迁移单 head、独立风险审查。
- 实际联调只保存脱敏结果、请求数、耗时和已报告 token，不保存源密钥或真实业务内容。
