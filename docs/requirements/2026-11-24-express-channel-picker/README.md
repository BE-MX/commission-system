# 订单快递渠道按付款方式过滤（2026-11-24）

新增 `DHL报关`、`FEDEX报关` 后，渠道从 8 个变成 10 个，平铺单选太乱。改成按付款方式过滤，并在保存时校验配对。

## 规则（亮哥 2026-11-24 定）

| 付款方式 | 可选快递渠道 |
|---|---|
| PayPal、TT、现金、支付宝、微信 | DHL普货、FEDEX普货、顺丰、自提、货代/海运 |
| 大/小/新莱莎信保（便捷发货） | DHL9610、FEDEX9610 |
| 大/小/新莱莎信保（报关）、对公转账（莱莎/旭和） | DHL报关、FEDEX报关 |
| 任意 | 其他快递 |

- 两个字段谁先选都行：先选付款方式，渠道只列出能用的；先选渠道，付款方式下拉把适用的组排前面。
- 改付款方式时，同承运商（DHL/FEDEX）自动切换，对不上则清空并提示。
- 旧订单不合规：打开时原渠道划线显示，保存时要求改正。
- 后端规则表唯一来源 `backend/app/invoice/shipping_policy.py`，前端 `invoiceSettlement.js` 镜像，测试锁定一致。
