# 回款功能交互原型

配套设计：[库存单自动回款与回款单管理](../2026-09-17-receipt-management.md)。

从仓库根目录运行 `python -m http.server 8767 --bind 127.0.0.1`，访问：

http://127.0.0.1:8767/docs/requirements/2026-09-17-receipt-prototype/index.html

也可以直接打开同目录 `index.html`。样式引用仓库现有 `frontend/src/styles/tokens.css`，移动文件时应保留目录关系。

所有客户、单据和状态都是演示数据；没有业务 API 请求，选择图片只生成当前页面的本地预览地址。刷新页面重置演示。演示日期固定为设计日期 2026-09-17，正式实现使用项目北京时间工具。

## 建议体验顺序

1. 新建回款单，默认订单余额 2,760.00 USD；切换生产单查看余额变化。
2. 不上传图片直接提交，或输入超额金额，查看内联校验。
3. 选择任意无敏感内容的测试图片、登记部分金额，查看新单详情与余额变化。
4. 顶部切换“提交结果”，模拟明确失败与结果待核对；失败可重试原单，待核对没有重试入口。
5. 点击“查看库存单设计”，保存无图草稿、尝试同步；补图后可自动生成一笔模拟回款。

原型不实现真实分页、日期筛选、远程订单搜索、管理员绑定/作废/修正，也不实现实际上传与跨系统事务。这些均在设计文档中定义。
