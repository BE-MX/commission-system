# 附件全链路切换验收

适用办公室、leshine.cloud、leshine.work；同时覆盖 hair/video 独立站点的公开资源入口。本文定义覆盖范围与放行条件，实际进度以 `../handoff.md` 为准。代码测试及 Nginx 候选预检不能代替生产三入口验收。

## 功能覆盖矩阵

| 业务 | 写入与读取链路 | 必须验收 |
| --- | --- | --- |
| 素材库 | 单文件、版本、目录分片；原件、缩略图、预览、ZIP、AI分析 | Windows临时路径、分片同入口完成、500MiB上限、ZIP256MiB与共享缓存预算、权限及删除墓碑 |
| 发货检验 | 手机/小程序/工作站照片视频；照片查看、视频Range、PDF取图 | LAN持久接收和同步状态分开，跨实例pending为503，ready后三入口字节一致，断网重试 |
| 客户素材 | 上传、缩略图、原件、下载、目录删除 | provider引用回填、私有链接、删除权限、500MiB网关与业务限制一致 |
| PM资料 | 版本上传、附件读取下载 | 独立PM鉴权、跨域入口登录后读取、50MiB上传 |
| 回款/发票凭证、内贸凭证 | 私有图片、OCR、预览下载 | 订单/客户权限不变，代理透传鉴权，旧引用仍可访问 |
| 培训、售后 | 培训文件、证据图片视频、SOP | 私有路径、原件读取；培训300MiB、售后视频200MiB |
| 设计预约 | 需求附件上传与下载 | 20MiB上传，后端解析到COS而非另一台服务器本地目录 |
| 设计生图/客户生图 | 会话附件、图库、生成输出、原图缩略图、产品素材、LOGO、AI读取 | 权限/邀请隔离，后台worker与HTTP共用同一存储key，保留原业务实例路由 |
| AI方案对话 | 图片、PDF/Office/文本上传与提取、私有读取、删除 | Linux不解析历史Windows根；AI收到真实附件内容 |
| 企业知识库 | 附件及正文图片、HTTP/MCP读取 | ACL和发布权限，引用图片解析，私有下载 |
| 洞见案例 | 截图上传、OCR、原图下载 | `insight`域；图片格式校验、真实多模态输入、案例权限、归档后404 |
| 头像、纪要附件、标签图片 | 上传和公开旧URL读取 | `avatars/card/tag_images`域和Nginx公开命名空间一致 |
| 展会 | 会话/试戴、场景、色板、假发图、派生缩略图、AI读取 | 历史Windows/Linux绝对路径归一，场景不可变版本/别名，删除引用控制 |
| 采购节 | 历史图片与新内容版本 | hash版本URL，公开资源读取 |
| hair/video | 既有公开资源 | 独立站点Nginx转北京私有桶读取，图片/视频Range及Content-Type |
| Colorwork | 工作台文件、metadata、Range、R2分片完成 | 机器接口公网404，完成幂等回执、不可变对象别名、未完成分片保留 |

AST清点显式 UploadFile 端点后，另查动态request.form、文件读写、FileResponse/StreamingResponse、静态挂载、浏览器链接、AI后台读取及独立工作台。接口数量不作为“全部功能可用”的证明。

## 特殊边界

- Excel/Word/PDF动态导出、仓库自带模板、导入/OCR临时文件不等于需迁移的持久附件；仍需验证功能本身，不将程序模板改成业务桶依赖。
- 用户填写的外部附件URL仍为外链，不拥有原始字节，COS迁移不能保证第三方链接长期可用。
- 旧 color swatch 生成服务含生成空PNG的占位实现，不能计作已完成的真实生成功能；它与已适配的 Colorwork 工作台不是同一链路。不得用空对象填补验收。
- 洞见旧引用目录为 `backend/uploads/insight`；标签图为仓库 `uploads/tag_images`。所有写实例都须清点并迁移；某台为空不能推断其他实例为空。
- 手机局域网接收不等待公网COS上传；同步完成前，异地访问有明确等待状态。办公室到云端带宽决定积压消化速度，不能承诺等同Wi-Fi速度。

## 三入口放行条件

1. 冻结所有相关写实例，补最后增量，逐对象校验源/COS大小和SHA256；DB每条有效附件引用都有可读取对象。缺失原件、同key异内容必须解决，不能静默跳过。
2. 发布候选明确包含哪些业务变更；数据库迁移链与生产revision一致，通过统一deploy入口执行一次。不stamp、不降级、不夹带未授权功能。
3. 三入口使用相同桶、region、prefix、域开关和相容的鉴权配置；实例ID各异，后台同步worker按实例运行。新增 `insight/tag_images` 也纳入清单和开关。
4. 公开路径先验证候选Nginx语法，激活后验证真实URL返回对象字节及COS来源标记；业务上传端点分别验证上限内通过、超限413，不能只测GET或health。
5. 每个表中业务至少取一份历史文件和一份新上传，依次从办公室、cloud、work登录读取：预览、下载哈希、Range、AI/OCR实际取图；同时验证无权限403/404、删除后不可读。
6. 手机连接办公室Wi-Fi，实际上传照片与代表性视频，记录文件大小、前台接收时间、同步耗时；暂停再恢复外网验证持久队列和重试。远端合成流测速不代替手机测试。
7. 检查worker无失败/积压、R2未完成分片无遗漏；回滚方案覆盖切换后新增COS记录。只关闭COS开关不能回退到未更新的旧磁盘。

以上条件未满足时保持原生产链路；本地测试标记不得写成生产已切换。
