附件中最稳定的共识：

- 产品与价格只是及格线，差异来自真实连接、专业判断和服务体验。
- 标准化询盘也可能来自高潜客户，不能按表面信息早退。
- 背调应进入首次沟通前，并输出客户生意、证据、未知和行动。
- 报价前建立相关价值，报价后每次跟进提供新价值。
- 头像、问候和短视频需要真实、生活化、可识别，但保持专业基线。
- AI 更适合把重复动作和经验判断结构化，人类继续负责真实关系与承诺。

## 三、培训内容采用矩阵

### 3.1 直接采用

| 培训方法 | 转化后的企业规则 |
|---|---|
| 陌生—认识—熟悉—信任—成交 | 新增 RelationshipStage，与 ProcurementStage 并行 |
| 头像与短视频建立“真人感” | 建立身份保真、隐私、圆形裁切和声明复核标准 |
| 先背调再联系 | 首触前完成最小身份/业务研究；不要求所有线索做无限深研 |
| 用客户姓名、时区与背景个性化 | 仅使用可追溯、非敏感证据；按工作时间而非私人作息 |
| 3 分钟讲清公司价值 | 固化为客户处境—相关价值—证据—路径—下一步 |
| 先价值后价格 | 信息足够时仍要快速透明报价，不能借机拖延 |
| 每次跟进提供新价值 | 增加 ValueAddedThisTouch 字段与跟进复核门 |
| 面对价格异议先共情再比较 | 对齐同等级、规格、批次、交期、售后和总成本 |
| 电话/视频提升沟通效率 | 先说明目的/时长，通话后书面确认 |
| 收款后持续同步 | 依据真实订单节点更新，不制造空消息 |
| 复盘写背景、问题、计划 | 增加证据、未知、阻断点、下一步和成功标准 |
| 公海客户结合历史下单周期激活 | 使用下单周期中位数和超期天数，不仅看固定天数 |

### 3.2 限制采用

| 培训做法 | 风险 | 可接受版本 |
|---|---|---|
| 3–5 秒决定第一印象 | 培训经验，不是已验证因果数字 | 作为设计启发，不写成效果承诺 |
| 15 秒 + 3 分钟介绍视频 | 可能变成统一模板和能力堆砌 | 15 秒只讲一项价值；3 分钟按客户类型变化 |
| 三次触达 | 容易机械追问或骚扰 | 三次不同价值，受同意、渠道规则和退订约束 |
| 竞品对比 | 可能攻击竞品或索取商业秘密 | 只比较可分享、可脱敏、同口径的规格与条款 |
| 利润空间分析 | 容易把假设写成确定收益 | 显示来源、假设、区间和客户确认 |
| 发货视频/集装箱号背书 | 泄露客户、订单和物流敏感信息 | 仅用公司拥有、已授权、已脱敏且可验证材料 |
| 高频电话与视频 | 可能打扰客户 | 有目的、有预计时长、尊重客户渠道偏好 |
| 强调生产紧张 | 容易制造虚假稀缺 | 只有当前系统可验证且与客户订单相关时才说明 |
| 意向金 | 法律、财务、退款与暗黑模式风险 | 现阶段不进入标准流程；先完成政策设计和显著同意 |
| 竞品发票核价 | 可能涉及商业秘密 | 只请求客户有权分享的脱敏规格/条款 |
| “请问跟谁比” | 过强可能引发防御 | 改为“为了同口径比较，方便分享等级、规格和服务边界吗？” |

### 3.3 明确不采用

| 内容 | 不采用原因 |
|---|---|
| 虚构同事/竞争者正在接触同一客户 | 欺骗，一旦识破直接损害信任 |
| 宁肯跟死不能等死、被拉黑也是肯定 | 把骚扰当努力，与退订/渠道规则冲突 |
| 不让客户离开、占满 1–2 小时 | 强迫式销售，不符合客户体验优先 |
| 意向金可退但客户通常不好意思要回 | 利用沉没成本和羞耻感，不可产品化 |
| 抓住如厕、清晨查看手机等私人场景 | 侵犯边界，不能作为企业触达策略 |
| 放大竞品 1% 缺点拿单 | 易失实、攻击竞品、忽略整体适配 |
| 随意展示监控、订单、集装箱和客户聊天 | 隐私、商业秘密和安全风险 |
| 培训宏观数字直接写入知识库 | 多处口径/单位可疑，且与销售 SOP 无直接关系 |
| 用行业/地区刻板印象替代个人证据 | 会导致歧视、误判和错误路由 |

## 四、现有知识冲突与风险清单

### 4.1 公司年限口径

- 文档 333/335 采用“1993 年起制造”。
- 文档 348 同时出现“LeShine 超过 14 年”和“约 30 年家族制造经验”。
- 文档 375/380 出现“33 years”。

处理：视频和话术优先使用稳定、可核验的“manufacturing since 1993”口径；品牌成立年限和家族经验在确认主体与证据前不要混用。

### 4.2 独家与区域保护

- 文档 358 把城市/州独家、色号保护写成核心卖点。
- 文档 359、375 明确要求“视区域可用性和管理层审批”。

处理：任何独家、区域、色号、NDA 只可表达为“可评估/可申请”，不得在头像、介绍视频、首触或自动报价中写成默认能力。

### 4.3 库存、交期与“最快”

- 文档 350 要求所有具体交期基于当前订单、库存和排产确认。
- 文档 358、379、380 出现当日/24 小时、2–4 天和“最快供应商”等强表达。
- 文档 350 还包含旺季、加急、外加工产品等多项条件。

处理：稳定材料可以说明“具备库存与国际配送能力”；具体 SKU、当日发货、到达时间和加急只从当前系统查询，禁止“fastest supplier”。

### 4.4 样品费与免费样品

- 文档 351：AI 不得承诺免费样品；某些抵扣项不向客户提及。
- 文档 378：“样品费将在首单退回”写成通用话术。

处理：以文档 351 和当前审批为准；未确认前删除通用退款承诺。

### 4.5 产品效果与收益数字

风险内容包括：

- 文档 358/375/377：2.5–3x markup、2.7x 利润增长、固定补货周期。
- 文档 376：1 年以上寿命、所有颜色使用 pure virgin ponytail hair、与低价产品结果的绝对比较。
- 文档 377：客户提价 20–30%、当前合作伙伴从 5 件做到月销 5 万美元。

处理：这些内容不得进入自动话术或介绍视频。只有具备已批准、可追溯、适用对象明确的证据时，才能作为脱敏案例并说明条件；否则改写为“帮助客户比较总拥有成本、批次表现和经营风险”。

### 4.6 售后承诺

- 文档 374/395 要求先取证、归因和审批，这是安全基线。
- 其他话术中“零风险、不满意可协商、使用一年”等容易被理解为保证。

处理：统一用“documented after-sales process；先收集订单、批次和使用证据，再按责任与权限给出批准方案”。不承诺零问题、固定赔付或无条件退款。

### 4.7 画像排除与转化诊断

- 文档 356/360 把 wigs、closure、hair bundles、frontal 设为排除/复核逻辑。
- 文档 381 的 CR-01 示例又提出某些黑人发产品方向可转其他产品线。

处理：以“当前正式目标产品范围”决定路由，不把产品方向等同种族。若公司实际上没有承接排除品类的正式产品线，则 CR-01 的“转其他产品线”应改为零售/合作方/排除池，不能让 Agent 承诺未存在的供应范围。

## 六、知识补充与 Agent 文档的边界

- 01-knowledge-supplement.md 是业务知识：告诉销售“为什么、做什么、什么不能做”。
- 02-agent-orchestration.md 是系统设计：告诉产品和研发“由哪个 Agent 做、传什么数据、在哪里复核”。
- ark-sales-persona-kit 是可执行 Skill：帮助新业务员产出头像与介绍视频脚本。

三者不能互相替代。把系统字段全塞进业务知识会难用；把销售原则只写在 Agent prompt 里又无法治理和培训。
