# 展会生图提示词配置与版本选择

## 目标与边界

运营在「展会营销 → 生图提示词」页面创建、复制和编辑任意数量的提示词版本，可启停和设默认。试戴与场景大片生成前选择版本，后端在每次生成请求中读取最新保存内容，无需部署或重启。当前已回滚的真实、柔光、美颜作为初始配置，迁移不改变三版效果。

本次配置化范围是展会效果图合成，包括主体、场景、构图、皮肤处理、发色、穿搭及收尾约束；面容分析、销售话术与 AI 提供商配置继续使用已有入口。场景选项的 key/中文标签属于产品目录，英文生图描述进入版本配置。配置页面不调用收费生图。

## 数据与执行

- `ark_expo_prompt_versions` 保存名称、说明、启用状态、默认标记、修订号和完整配置 JSON。默认标记采用可空唯一槽，保证至多一个默认版本；默认版本不能停用，先切换到另一个启用版本。
- 配置由模板分区、场景描述及穿搭/首饰候选组成。模板只允许明确列出的占位符，不执行表达式或代码。空的可选分区表示不追加该文案，不从代码补默认内容。
- 迁移 139 在新表写入三个旧版完整配置；运行时只读取数据库，迁移种子不作为缺失配置的运行时 fallback。数据库为空/所选版本停用时阻止生成并给出明确反馈。
- 创建结果前，读取并锁定所选版本，将最终展开的提示词、版本名称/修订号、输入图片路径和尺寸保存为 `ExpoResult.prompt_snapshot`。后台线程仅使用快照；编辑、停用或改默认不影响在途任务及历史结果。
- 新请求使用 `prompt_version_id`，移除旧的固定枚举接口。历史 `prompt_variant` 字段只保留既有数据，不再写入；历史无快照时显示「历史记录未保存提示词」，不伪造旧提示词。
- 管理 API 使用现有 `expo:admin`，试戴版本选项使用 `expo:write`，不向共享屏返回提示词正文。详情/快照正文仅管理员可读。
- 编辑需提交 `expected_revision`；并发修改返回冲突，避免无声覆盖。配置验证和快照生成先于额度扣减，同批次使用同一修订号。

## 页面

管理页以版本列表为入口，新建默认复制现有默认版本，复制按钮可从任意版本创建。编辑器按「主要提示词 / 发色与穿搭 / 场景描述」组织，提供占位符帮助和展开预览。保存明确提示「下一次生成生效」。启停和默认版本操作有加载状态与失败反馈，未保存修改有离开保护。

试戴与场景页共用版本选择器，加载启用版本并选中服务端默认项；切换选择立即影响下一次请求。进入生成前页面、重新获得焦点及手动刷新时更新可选列表。加载失败提供重试，不回退到代码内旧版本。历史结果显示当时版本名称；管理员可查看实际提示词。

## 验收与交付

1. 旧版种子在固定场景/图片/随机选择下与回滚版本生成的最终提示词一致。
2. 新建、编辑、复制、启停、默认切换、占位符错误、版本冲突均有隔离测试；非管理员不能修改。
3. 生成读到最新配置；生成中编辑后快照不变；无效/停用版本不扣额度、不创建任务。
4. 前端版本选择真实联通 API，两个生成入口都传所选 ID；表单保存/错误/刷新/未保存修改与窄屏布局可用。
5. 只在隔离数据库验证迁移和业务行为；构建、约定检查与独立审查通过，记录生产迁移和部署前置条件。代码实现不等于生产发布。
