## 已实现

- 个人、团队、AI 三个视图；管理者可全部并排或选择个人；时间范围、自定义日期、热力图/曲线柱状图、底部键盘可操作切换条及窄屏布局。
- 次数按记录作者，客户覆盖按当前责任人，历史客户回退档案归属。未跟客户从最近接手时间起算；周日和配置非工作日不计断档，今天不算完整断档日。团队人数不足四人不返回均值。
- 覆盖、结果、障碍、质量、约定任务和市场信号下钻与主统计共用范围；约定兑现分母包含到期未完成及顺延任务，不能用只看已完成任务替代。
- AI 个人四类、公司四类建议；证据 ID 与版本绑定，读取时重新核验；交接后原负责人的客户行动建议隐藏。订单对照另校验订单权限。
- 公司脱敏建议单独使用匿名聚合输入生成，不能把包含客户原文的模型输出简单抹掉店名后复用；公司共性至少三家，成交复盘/频率观察至少十家实际输入样本。读取时复核有效输入客户集合及成交状态，样本变化则隐藏旧判断。
- 反馈按反馈人独立保存；每日沿用评语通过原始建议 ID 保留反馈，旧页面提交也作用于同一建议。客户建议转待办需写权限与客户可写范围，重复及并发点击只产生一个待办。
- 生成状态落库，独立双线程池；每分钟扫描恢复排队任务，执行令牌防止超时的旧执行器覆盖结果。运行超过十五分钟、排队超过二十四小时标失败；保留上一份完成快照。关闭生成开关后不启动排队任务，已开始的执行可完成。
- 周一北京时间 07:30 全量生成，分析截至周日的近六十天；周二至周日 07:30 刷新个人成交/变冷建议，沿用其余评语。手动刷新每人每天两次，服务端事务锁处理跨请求并发配额与重复入队。
- 跟进设置增加统计名单、非工作日和生成开关；AI 预设 `domestic_followup_insights` 可在后台调整，业务调用统一走 facade。
