# 公海筛选规则配置

在客户经营研究中心增加可视化规则入口，支持高级 JSON 双向编辑。成交条件为（至少2单且总额>1500美元）或单笔>1000美元或仅样品订单；其他条件同时满足。Instagram优先排序，Facebook或电话同样可入选。产品任一命中即可；平型按Flat Tip识别。缺少下单日期或跟进日期默认不视作沉默客户，明确展示资料缺失数。

实现与验收：严格类型契约及版本配置表；预览与批次共用筛选器；定时任务读取已保存配置；规则快照保证历史批次可核查。页面配置金额、国家、联系渠道、产品、周期与配额，并展示筛选漏斗。独立隔离数据库测试阈值、空值、归属、排序、版本冲突和批次幂等，前端构建及浏览器验证。仅本地交付，不执行生产迁移或部署。

## 交付与验收

入口：客户经营 → 背调中心 → 公海筛选规则与批次。默认表单；高级JSON不是必填步骤。规则保存启用，修改不追改已有批次。样品默认仍须产品符合；缺跟进日期默认排除，这两项均有可视化开关。客户范围与DNC不可被JSON关闭。

| 改动前 | 改动后 |
|---|---|
| 手填策略版本及配额JSON，经营条件未接入 | 成交/国家/渠道/产品/周期/配额分组配置，JSON可双向编辑 |
| 不知道筛选为何为空 | 预览符合数与各原因排除数，缺日期明确显示 |
| 手工批次与定时默认参数分散 | 保存版本供后续批次和调度共用，每批保留快照 |
