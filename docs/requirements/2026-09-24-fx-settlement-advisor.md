# 结汇决策助手（2026-09-24，本地实现）

## 用户入口与边界

登录方舟后从「订单管理 → 结汇决策助手」进入。`fx_settlement:read` 可查看行情与计算方案，额外拥有 `fx_settlement:write` 才能调用 AI。权限由现有角色管理分配。只接受**已到账**美元，扣除必须预留给美元付款的本金；未来应收款、远期锁汇、交易执行和实际成交价承诺不在本版范围内。输入和结果不保存到业务表。

过去一年按周一至周五比较的独立交付物见 [HTML 分析报告](../reports/2026-09-24-usd-cny-weekday.html)。报告发现原始均值与完整周配对排序相反，因此工具不以星期几作为自动结汇信号。

页面先展示中国银行美元现汇买入公开参考价及当日较早参考价；每 60 秒尝试刷新。报价超过 30 分钟不参与计算，用户可改填 15 分钟内从银行取得的实际报价和报价时间。中国银行按每 100 美元报价，服务端换算为人民币/美元。日度历史来自美联储 H.10 的 FRED DEXCHUS 序列，按周发布；最近 5、20 个观测日变化是滞后趋势证据，超过 10 天即标记不可用于趋势判断。来源和两种数据的时间戳均在页面展示；来源暂不可用时不虚构报价或走势。

用户填写已到账美元、预留美元、现需补足的人民币净缺口、剩余部分最晚结汇日、压力情景下可接受的人民币差额和假设跌幅；可选填报价外费用及美元/人民币年化利率。结果给出当前至少要结汇的美元、风险预算内最多可等待的美元、立即/均衡/机动三个方案及跌/平/涨情景。费用与利率默认 0，跌幅默认 2%，这些是用户可修改的测算假设，不是市场预测。金额以十进制计算至美分，日期按北京时间，利息按单利实际天数/365。后续分批日期是执行提醒，不包含各日汇率预测；银行休市需提前操作。

约束顺序：先预留美元，再用最少的即时结汇金额覆盖人民币净缺口；如全部可结汇美元仍不足，显示缺口并不挪用预留款。再按用户设定的跌幅与费用/利率，限制等待本金，使该**设定情景**与全部即时结汇相比的测算差额不超过预算。最大差额填 0 或到期日在今天时，全部可用美元立即结汇。超出假设的实际跌幅可能造成更大差额。历史某个星期几的均值不作为交易信号，也不宣称未来收益最大化。

AI 调用使用平台 AI 网关预设 `fx_settlement_advisor`。启动时仅从已启用的已知文本预设克隆模型配置；无可用文本模型时规则测算仍可用。AI 仅可返回一个候选方案 ID、预先生成的理由 ID 和重新判断条件 ID；服务端重新校验、用服务端数据组装数字与解释。模型响应无效或不可用时显示规则方案和明确状态。调用限频为单进程每用户 30 秒且同时只允许一个请求；网关仅留 metadata 快照。页面明确告知用户本次金额和条件会发送给系统配置的模型。AI 与规则均只提供决策辅助，不提交银行交易。

## 手机应用入口（2026-09-26）

- 手机直达同域 `/fx-settlement`，独立于后台侧栏；手机打开旧地址 `/invoice/fx-settlement` 会保留查询参数和锚点转到新入口。桌面原菜单仍保留双栏，并提供“手机应用入口”链接。
- 沿用方舟账号和 `fx_settlement:read/write` 权限。未登录、API 会话过期与退出登录均保留结汇目标；手机登录后不跳素材站。没有读取权限时留在登录页，可更换账号或联系管理员开通。
- 800px 及以下使用底部“行情 / 测算 / 方案”导航；页面内切换保留当前输入，完成测算自动切到方案。金额字段使用数字键盘、至少 48px 输入高度；方案比较为纵向卡片，底部操作与导航留出安全区。修改条件或报价过期后标记旧结果。
- 行情页有“添加到手机桌面”指引。iPhone 使用 Safari 分享菜单，Android 使用浏览器安装/添加到主屏幕；微信或钉钉中提示改用系统浏览器。manifest `/fx-app/manifest.webmanifest` 的 id/start_url 固定为 `/fx-settlement`，独立图标 180/192/512px；`scope=/` 容纳登录路径，权限仍由路由及 API 控制。
- 与发货质检共用 `public/standalone-apps.js` 管理安装元数据，应用间切换替换 manifest/title/icon，离开应用恢复普通 viewport。未加入 Service Worker，不缓存业务数据，不提供离线测算。刷新或关闭会清空当前输入和结果。

手机回归：`python frontend/tests/fxSettlementMobile.browser.py`（先在 frontend 运行 `npm run dev -- --host 127.0.0.1 --port 3079 --strictPort`）。所有 API 在浏览器内模拟，不连接真实后台，不调用收费模型。覆盖 320/390/430/768px 与 1440px 桌面、旧入口分流、匿名登录、刷新、401 回跳、无权限、只读按钮、无效折叠字段、测算/AI/旧结果、错误重试和手填报价。真实 iOS/Android 桌面安装需发布后实机验收。

## 上线与验证

本变更无新表或 Alembic 迁移。启用前由管理员在角色管理分配 `fx_settlement:read` / `fx_settlement:write`，确认 AI 设置中的文本预设可用，再对照实际银行可成交价和内部用款安排做一次业务验收。本次合并推送仅交付代码，未部署，生产未接入。

定向后端测试覆盖报价解析与过期、北京时间、预留款、现金缺口、风险预算、AI 非法输出和权限；前端构建、导航权限测试及 Chrome 1440px/390px 登录态联调覆盖行情、计算、AI 结果、输入变动提示与横向溢出。浏览器联调用隔离模拟接口，非生产模型与真实成交价验收。数据源请求曾在开发机成功，仍须在目标部署网络下核验。
