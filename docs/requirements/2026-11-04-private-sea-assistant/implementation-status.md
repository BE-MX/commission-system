## 已实现

* `/client-desk` Vue 页面接入真实 API，包含客户筛选/档案、个人资料、共享等级 CAS、建议反馈、手工跟进、日期、寄样、会话关联/忽略/撤销、时间轴证据与重新分析。窄屏列表与详情分屏，返回保留位置；请求迟到、失权与提交失败有对应处理。
* `app/client_desk` 四表、迁移 `250_client_desk`、权限与试点范围、镜像和 overlay 范围、订单双口径、合格背调和 WhatsApp 授权读取。正文修改、撤回、关联或授权变化后旧派生内容失效。读取批次先限定私海与有效关联。
* 八项候选规则、冷却、全候选快照、40 个例行名额、15% 合格留出、每客户每天三次手动分析、desk_v1 资料包、引用/风险验证、模型白名单与 metadata 日志。租约领取、调用前意图、迟到防护和 ambiguous 不自动重发。
* 办公室单活 06:30 扫描、每分钟队列、08:40 早报。逐客自动完成隔离失败；早报只读实时复核、日级发送意图和单次票据。钉钉 SSO 尚未具备可验证身份时，早报入口续接本人方舟登录。
* `scripts/client_desk_p0.py` 准备与显式分析评测材料，`client_desk_export.py` 只读脱敏导出，`client_desk_report.py` 合并评分和漏项 JSONL。重复快照按实际截止去重，观察窗口不足、转出或失权有明确排除，指标可按完整窗口复算。

质量评价用 `feedback_at` 表示最后一次明确质量变更。完成事实用 `done_at`，稍后计划用 `snoozed_until`，两类行动不会更改质量时间或抹掉人工评价。重复反馈不延长冷却，短冷却不会覆盖长冷却。

## 开通前所需证据与配置

1. 按验收手册完成 U1/U2/U4～U8、真实单人五个工作日评测和两人试点。当前没有真实客户评分、模型效果或钉钉客户端验收数据。浏览器的接口模拟验收与隔离后端测试分别提供证据。
2. 明确 `CLIENT_DESK_PRESET_NAME`、供应商 ID 白名单、试点用户、早报 HTTPS origin、独立签名密钥和年度日历。全部通过 Settings 配置，开关默认 false，名单和供应商白名单默认空。年度未知时工作日计算阻断。
3. R5 的样品/大货与订单状态在镜像中缺乏统一已确认语义，使用 `CLIENT_DESK_RULES.order_classification` 的 sample_field、sample_values、bulk_values、status_map 配置校准。未知分类客户保守停止复购推断，界面展示资料缺口。配置字段必须属于现有镜像列，查询不插入外来 SQL。
4. 目前连接器只证明 partial 历史覆盖。共同归属用户缺少完整可靠的出站覆盖时，各自独立评估并记录仲裁降级，避免不可信去重漏提醒；不会声称已实现可靠的全历史仲裁。
5. 本地成果待正常 Git 审阅、集成与生产发布流程。四表迁移只在获授权的部署入口运行；试点通过并全员开通后再执行旧入口下架。
