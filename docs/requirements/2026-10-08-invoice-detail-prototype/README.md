# 订单发票关联详情交互原型

本目录静态原型保留为设计参考；真实页面与 API 已于 2026-10-08 实现，见[实现与验收](../2026-10-08-invoice-detail-implementation.md)。`assets/implemented-*` 为真实组件的隔离验收截图。

功能设计见 [设计文档](../2026-10-08-invoice-detail-design.md)。本目录为静态评审产物，所有业务数据均为模拟数据，没有任何业务 API 请求或持久化写操作。

## 打开

直接用浏览器打开 `index.html` 即可；保留本目录相对于仓库的路径，它引用 `../../../frontend/src/styles/tokens.css`，从方舟现有设计系统读取颜色。

HTTP 预览可以在仓库根目录运行：

```powershell
python -m http.server 8768 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8768/docs/requirements/2026-10-08-invoice-detail-prototype/index.html`。初始展示预售示例弹窗；关闭后点击列表发票号重新打开。弹窗底部可切换十个场景，上方选择器在关闭弹窗后可操作。

## 本次验证（2026-10-08）

- 浏览器实际操作：1440×1000 桌面、390×844 窄屏；正文独立滚动、表格内部横向滚动，手机页面无横向溢出。
- 发票号入口、三标签、进度卡跳转、出库单与批次展开、出库关键词筛选、回款用途筛选（运费 2 笔）、无结果状态、回款资料与模拟凭证展开均验证。
- 预售部分履约为回款 60%、实际出库 50%；库存结清为两条 100%；已生成待出库为回款 100%、出库 0%；草稿/空数据、核验异常、权限提示场景验证。
- Escape 关闭后焦点恢复至原发票号；标签方向键切换验证；未添加高频动画。
- `node --check` 检查 `app.js`、`fixtures.js` 通过。浏览器未捕获 JS error/warn。
- Node 临时校验核对六场景的保存行金额、发票费用合计、出库数量、商品/运费回款分组，均自洽。
- 直接运行仓库纯函数 `settlement_pricing.quote_settlement` 验证本例第一批商品款 920.00、第二批 613.33、末批抵扣预付款后 122.67；没有访问数据库。
- 独立 agent 审查已完成。已修正预售主单金额与本批余额混用、进度四舍五入提前判完成、用单价重算行金额三项；样例备注改为“分批交付”。
- 项目约定检查通过；Git 巡检使用 `--no-fetch`，结果为本地快照。本工作分支保留设计与原型，未 commit、push、合并或发布。

## 异常提示补充（2026-10-08）

- 列表和弹窗的发票号右上方增加红色静态荧光框，分别显示订单异常、出库单异常、回款异常；多项同时展示。弹窗异常文字可以点击，直接切换对应详情标签页。
- 左侧三个导航名称右上方分别显示黄色叹号。角标按当前可见权限内的全部示例单据汇总，查看正常发票不会清除其他发票的异常；异常解除后消失。
- 正常待生成、未同步、回款未生效不作为异常；作废回款和无权查看的关联单据不参与异常提示。正式产品需接入完整可见范围的异常汇总接口，不能使用当前分页结果代替。
- 浏览器验证单项异常、多项异常、恢复正常、三类异常文字跳转；打开正常发票后全局角标仍保留。390×844 下发票号和异常提示换行，页面宽度保持 390px，无横向溢出。浏览器未捕获 JS error/warn。
- 十场景状态校验、权限隔离、作废回款排除、原始出库 `status` 异常映射及 JavaScript 语法检查通过。独立 agent 审查通过；荧光框无闪烁或持续动画。

## 动效与验证范围

| Before | After | Why |
| --- | --- | --- |
| 高频标签与业务列表切换的潜在动效 | 保持即时切换，不添加位移、交错或弹性动画 | 保障业务浏览速度，键盘操作不等待动画 |

打印按钮调用浏览器原生打印，打印 CSS 只展示订单；本次未执行实体打印。复制按钮有剪贴板权限失败反馈；本次未修改用户剪贴板。生产数据库、真实权限、出库事实来源、回款 API 去重/核验没有通过本原型验证；正式接入的缺口与回归场景见设计文档。
