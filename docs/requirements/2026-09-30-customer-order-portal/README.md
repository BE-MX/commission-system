## v1.73 范围剥离：门户边界止于方舟 PI（2026-10-08）

业务决定：门户功能边界到生成方舟正式 PI 为止，回款、出库与后续履约完全由方舟既有模块按原有流程处理。据此：

- 建票不再创建 ReceiptIntent 草稿；`create_invoice` 对 `source_type="portal"` 跳过既有 `save_draft(new=True)` 钩子，其他来源发票不变。门户 PI 的回款与历史发票同口径：手工回款或发票编辑（惰性 eligible=0 草稿）。
- v1.96/v1.97 价格写入口当前权限屏障保留，不再向回款/出库 writer 扩展。
- 旧自动回款 `generate_ready` 主体政策与接入、显式回款生成内核接线、后台出库执行器切换与发布围栏、全部 writer 共同协议划入独立加固专项，从门户上线门禁移出，不再阻断门户发布。
- 收窄后的门户上线门禁：迁移 126 链与 175/176 真实库演练及单 head、库存来源/合同价/SMTP/存储真实联调、边界内 64T 子集、B01–B07 经营参数、双客户双业务员试点、统一部署入口发布与恢复演练。
