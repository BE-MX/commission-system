## 已证实的能力与风险

1. 同一订单可以建立至少两张不同编号的部分待出库单，精确关联同一个 `order_record_id`。库存不足会阻止写入，但不能代替订单数量控制。
2. OKKI 订单详情在两张待出库单创建后，`to_outbound_count` 与 `task_outbound_count` 仍均为 0；第三张导致累计超过订单数量时，远端仍返回成功。因此发送前必须完整扫描关联出库并计入本地任务占用，且必须约束方舟以外的出库写入者。仅依赖 OKKI 订单详情计数或本地数据库锁会超发。
3. 无商品的费用订单可作为独立运费回款目标；它同时是一张金额为 USD 0.01 的销售订单。方舟统计必须在第一张正式运费单产生前，以持久远端 ID 映射排除该角色。亮哥已确认接受小满原生销售报表包含运费订单，前提是在相关页面和交付说明中明确标注口径。
4. 该费用目标允许独立回款，回读 `collect_status=1`。这符合当前规格的资金生效条件；`finance_verify` 没有额外审批记录。非零银行手续费、远端改额/删除恢复、实际出库状态 2、外部并发超收尚未实测。
5. 当前生产 `PRESALE_SETTLEMENT_ENABLED` 仍关闭。任务分支已补上持久运费目标、目标级回款、分批待出库执行器及显式确认状态 2、异常核对与明确失败重试。小满编辑既有出库明细须携带 `outbound_record_id`；发送前后还核冻结单价、单位、行 ID、成本单价和资金状态。单独的真实状态 2 接口契约已验证；方舟执行器端到端链路尚未验证，能力策略仍固定关闭。
6. 2026-09-28 在同一租户对专用出库单 `105815112061333` 执行了真实状态 1→2 编辑。回读状态 2，远端明细 ID `105815112061358`、数量 1、销售单价 USD 0.01、单位 `Piece`、成本单价 RMB 0 均与状态 1 回读一致。状态 2 出库单经精确 ID 删除成功、有效列表不再包含；关联订单改草稿后删除，客户从公海删除，详情 404 且有效列表无记录。该探针没有实际货物流转；未在创建前记录库存快照，不能据此断言库存数量已恢复。
7. 独立审查后补了出库状态 2 的远端有效回款全集及主单有效性核验，逐笔要求分配给本批的回款仍在有效列表且状态为 1；确认实际出库前使用同一核验。首次回读即状态 2 且没有状态 1 明细 ID/成本基线时保持异常待核，不自动记为已出库。已出库单若重新显示状态 1，也只进入异常待核。定时任务每小时复核已出库批次资金，并记录每次尝试时间，即使远端读取失败也轮转到后续任务；新批次报价会核验历史批次的有效回款，失效或新增未分配回款将阻止继续分批。相关隔离回归 40 项、受影响领域合计 205 项通过；尚未在真实方舟执行器和数据库上验证。
