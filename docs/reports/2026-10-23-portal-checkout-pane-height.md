# 结算页双栏高度调整

用户反馈桌面结算页左右两个滚动区域过矮。修改仅作用于有选购内容的桌面结算页（宽度 >1000px）。实现分支 `codex/portal-checkout-height`。用户已授权与 PI 字体修复一起提交、合入 main 并推送；最终交付以 Git refs 回读为准，本次不部署。

- 页头及导航统一为 64px；标题改为紧凑单行布局，收起重复的装饰眉标；页脚上下留白缩到 4px，保留联系人和品牌文字。
- 内容区域继续用剩余视口高度分配左右两栏；正文、表单与按钮字号不缩小；手机端保持原上下排布。
- 未新增动效；金额、报价、提交及恢复逻辑没有改动。

1440px 宽的实际浏览器测量：

| 窗口高度 | 修改前双栏高度 | 修改后双栏高度 | 增加 |
| --- | --- | --- | --- |
| 900px | 537px | 703px | 166px |
| 640px | 376px | 443px | 67px |

`checkoutFees.browser.mjs` 增加高度与顶部位置回归断言，同时保留实际滚轮独立性、边界不带动整页、费用/付款切换、确认提交和手机端检查。使用本地实际 Vue 应用及拦截 API，未请求生产服务。目标视口截图由主代理核对；属于局部样式修改，未派独立视觉评审。

浏览回归连续三轮通过；门户构建、增量约定检查和 diff 检查通过。截图与实际尺寸 JSON：`tmp/checkout-height/before/`、`tmp/checkout-height/after/`；`checkout-top-900.png` 对比上方留白与双栏高度，`checkout-independent-640.png` 覆盖短屏滚动结果。
