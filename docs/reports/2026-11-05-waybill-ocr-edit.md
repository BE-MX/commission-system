# 运单 OCR 识别后修改单号

## 行为

- 物流跟踪的运单上传页、验货单的上传物流单弹框共用表单，识别后可以编辑或补填运单号；图片预览、收件信息和 OCR 来源保留。
- 即使识别出的号码已经存在，也可以继续纠正。改号立即撤销旧重复提示和已有运单关联入口；失焦清理空格并重新查重，迟到响应不能覆盖新号码或重置后的表单。
- 保存时对最终号码重新查重；重复号码或查重失败不提交。提交锁在异步校验之前设置，防止重复点击。后端原有唯一性校验和 409 处理继续保留。
- 提交和关联期间禁用编辑。失焦查重不禁用保存按钮，避免编辑后首次点击被吞掉；最终校验由保存函数统一完成。
- 不改数据库、后端接口或权限，不迁移 Kimi 旧工作区内无关的未提交代码。
