# 导航文字角标玻璃材质修复

用户反馈“BY 加程”这类标签失去发光、玻璃和半透明质感。内置iconBadge、可配置文字角标及管理页预览原有独立渲染/样式；本次统一复用NavigationTextBadge，删除废弃的普通实底标签样式。

- 金、蓝、灰标签使用同族浅色文字、20%→7%透明渐变、半透明细边、内高光和柔和9px光晕，backdrop-filter为blur(8px) saturate(1.35)。颜色均来自既有token，不新增常驻动画。
- 图标角标保持右下角小标签位置，名称右侧标签不再包在名称的截断容器中，避免切掉标签和光晕。侧栏与配置预览共用组件。
- 不支持backdrop-filter或偏好减少透明效果时使用更实的背景，关闭模糊；选中菜单上的标签改用深色文字保持可读性。
- 真实Vue浏览器核验左右两处计算样式一致；三种色调、两种位置、折叠后角标及减少透明效果均可见，无裁切。隔离fixture为frontend/tests/fixtures/navigation-badge，所有请求本地模拟。
