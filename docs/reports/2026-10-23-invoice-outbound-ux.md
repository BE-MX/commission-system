# 订单发票与出库页面优化

日期：2026-10-23。分支：`codex/invoice-outbound-ux`，基点：`569b1fe5`。本地实现与隔离验证完成；用户已授权提交、合入 main 并推送，最终交付以 Git refs 回读为准；未部署。

## 按评估顺序实现

| 顺序 | 问题 | 本次实现 |
| --- | --- | --- |
| 1 | 金额名称和币种不清 | 列表与详情统一“应付合计”；编辑页基础金额标注“不含手续费”；每行保留真实币种；详情“附加费”改为“手续费” |
| 2 | 0% 默认显示进行中 | 新增基于关联事实的状态标签；保留进度精度、超额、权限、核验失败和快照语义 |
| 3 | 删除与高频操作并列 | 删除移入更多菜单分隔区，保留独立删除授权和同步／处理中禁用条件 |
| 4 | 订单首屏空间少 | 删除重复副标题，概览默认紧凑且可展开／收起，记忆偏好；缩减操作列，创建时间默认隐藏，保留已存列偏好 |
| 5 | 明细工具多且列名偏技术 | 产品和配件列名本地化，复制／清空收进明细操作菜单；规格及选填列按钮提供选中语义，保留价格、数量、小计固定列和结算栏收起能力 |
| 6 | 出库多动作同级 | 保留快捷打印、库存入口；Word 下载移入更多；日期按北京时间只显示日期 |
| 7 | 库存诊断字段挤占宽度 | 实存／不可用移入既有行展开区，简表聚焦本单数量、可用、缺口、状态和同步时间 |
| 8 | 预售结算长内容混排 | 本批商品／结算确认分节，历史记录可展开；活动或待确认批次自动展开；原字段、冻结及恢复逻辑不变 |
| 9 | 打印入口不一致 | 出库更多菜单补可选预览，复用 ShippingPrintDialog，保留原快捷打印；桌面预览扩至受视口约束的 960px |

金额计算、资金抵扣、库存判定、写入 API、授权种类、实际出库标准、A4 打印内容和脱敏均保持现有契约。本次没有数据库或生产业务写入；远端操作仅限已授权的 Git 交付。
