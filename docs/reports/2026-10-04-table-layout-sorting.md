## 结果与原因

主管关系与客户归属的筛选区继承全局 sticky 的导航偏移，页面为了装饰层又将位置改为 relative，导致视觉下移而布局高度不变，覆盖操作行和表头。全局卡片内筛选区清除 top/bottom 偏移，操作行正常占据文档流；同步修正内贸订单、素材统计/收藏、设计统计、生产单打印、物流列表/详情、展会脚本库等同类样式。

表头排序覆盖 174 个 Element Plus 表格组件及记录型原生表（公开库存、生产明细、结汇比较、案例优化方向、PM 任务）。数据列默认启用排序，模板列明确原始字段或展示值；选择、序号、操作、媒体预览等结构列不提供排序。公海去重统计没有 API/持久化数据来源，恒空列明确关闭排序。

分页排序覆盖完整授权筛选结果，先排序再分页。切换回第一页，翻页保留排序，清除恢复默认；不会提交待查询筛选输入。普通列表和大型镜像在 SQL 白名单内排序，已有完整计算的派生列表在现有授权结果上排序后切页。银行卡仅在点击掩码列时为完整筛选结果生成掩码排序，不输出或存储明文；其他列继续 SQL 分页。树表递归排序同层，保留月份分组和父子关系；编辑型明细保留原始编辑索引。
