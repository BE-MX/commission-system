# 客户门户全页设计检查与优化

2026-10-23；分支 `codex/portal-oil-ui`。本地优化已验证；用户已授权提交、合并 main 并推送，最终状态以 Git refs 回读为准；未部署。

## 方向与边界

北极星：保留 LeShine 的暖白、墨色、品牌金和产品照片，让专业采购用户清楚选品、核对并提交请求。门户保留自己的字体、布局和组件，不引入主站后台样式。沿用实际产品图片，不生成替代产品图；测试色卡使用纯色夹具。

本次以 App.vue 的路由及实际挂载组件为页面范围。没有独立账户页，账户信息和退出入口位于共享页头。`/cart` 是选购入口别名；`/orders/:id/proposal` 使用请求详情组件。没有新增业务入口、支付、库存写入或后端接口。

## 修改及理由

| Before | After | Why |
| --- | --- | --- |
| 申请与激活布局类无样式 | 共用门户表单、卡片、间距、成功反馈与窄屏规范 | 新客户入口有清楚的主动作和阅读顺序 |
| 未登录邀请链接落到登录页 | 初始路由解析当前路径并先清除 token | 用户能到达激活页，地址栏不保留邀请凭据 |
| 激活表单返回 `sendCode` 函数而未执行 | 调用 `sendCode()` | 点击发送验证码进入实际的请求流程 |
| 多处 7–12px 小字，缺货色卡整体半透明 | 支持信息以 13px 为基准；缺货用虚线和删除线 | 库存状态、时间、条款和色号更易辨认 |
| 规格页三块内容延迟 500ms 出现 | 移除入场位移及交错延迟 | 高频选择立即可用，不让内容等动画 |
| 窄屏数量与主按钮争用空间 | 数量独立一行、主按钮通栏、侧栏数量控件 44px | 触控更清楚；中等宽度页头可换行 |
| 普通摘要使用重浮层阴影 | 独立轻阴影 token | 产品与主动作优先，摘要安静辅助 |
| 核对区写着所有细节已确认 | `Review your request.`，保留待确认运费与金额 | 标题不暗示尚未发生的确认 |
| 对比中重复列出双方都为空的地址字段 | 仅省略双方都空的字段；实际清空仍显示 | 缩短对比，同时保留变更依据 |

删掉结算与请求页重复副标题、登录装饰序号；将面向客户的 server 说明改成核对动作。保留库存核对时间、非预留说明、方案有效期和确认条款；保留品牌页脚，因为联系入口与整体品牌收尾仍有用途。未增加动效；保留既有受限 hover、按压反馈与 reduced-motion，删除高频选品入场动画。
