## 配置规则

- 普通业务通过稳定预设名调用，预设名是业务接口标识；模型、提供商、提示词和调用参数均可维护。业务权限、工具白名单、预算、配额、任务状态机、看门狗及上传/下载安全边界继续由服务端负责。这些不是上游模型的可调参数。
- 生图 Studio 上架、显示名称、可选尺寸/质量与测试类型分开；同协议的新型号不需要更新代码枚举。全新协议和未实现的 ACCIO 外部派发仍需要适配，配置页面不会虚报其已经可调用。
- 默认优先级：提供商基础超时 → 提供商运行配置 → 预设 `transport` 覆盖 → 当前业务请求的上限。尺寸/质量由本次用户请求覆盖预设默认；展会按已冻结场景尺寸调用。
- 网络超时是单次 HTTP 各阶段约束，不是整个多次重试工作流的总截止时间。Studio/客户生图按租约预留处理余量；展会图片/分析单次最多 300/120 秒，原有业务看门狗仍有效。
- 未填写的字段沿用现有默认；清空结构化字段删除该覆盖值。完整 JSON 格式错误或新参数校验失败时不保存。内部 `transport`、`workflow`、`studio`、下载域名与测试参数不会发送给模型。
- 已排队图片任务继续严格检查配置指纹；同一知识库任务的正文与语义核验使用校验后冻结的同一配置，租约按该配置计算。
- TLS、非重定向模型请求、图片下载域名/地址/类型/大小限制、计费不确定时不自动重放等保护保留。调用安全上限不能通过扩展参数覆盖。
