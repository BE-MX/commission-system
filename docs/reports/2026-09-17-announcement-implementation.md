# 公告管理实现与验证

分支：codex/announcements；基点 2609626f。独立 worktree 本地实现；未做生产变更。

## 已落地

- 公告列表、新建、查看、类别过滤、编辑保存、审核发布、置顶、撤回、草稿删除。
- 公告库→类别目录→文档映射；复用版本、审批、图片、成员与检索，读者只看发布版本。
- 发布自动持久入队，图文顺序发送，长文分片；失败重试、结果不确定人工结案。
- 北京时间周一 09:00 上周周报；AI 原句摘要带来源，失败降级目录，手动生成预览/发送。
- 管理设置：类别、成员、机器人目标、执行账号、AI 预设、通道测试与投递记录。

## 启用步骤

1. 经授权按项目入口发布，先在隔离 MySQL 环境演练迁移 155，再执行目标环境迁移。
2. 分配公告权限，管理员初始化公告库、维护类别和成员；执行账号须保持公告阅读与库 ACL。
3. 配置应用机器人凭据、群 openConversationId/robotCode、有效 AI 预设与公告访问域名。
4. 管理员显式发送图文通道测试，在群内确认文字和图片后点击验证；再开启公告推送和周报开关。
5. 首次审批发布和周一任务检查投递回执与群中实际排版。回执仅表示接口接受。
