## 设计与范围

用户任务是员工在「客户门户 → 下单请求 → 详情 → 处理原 PI」核对单据并处理修改提案、发布或作废。设计北极星：先辨明正在核对哪个 PI 版本，再核对商品和金额，找到对应操作与导出。

采用现有 Ark 品牌的单据核对工作区：保留 DESIGN.md 的字体、金色、tokens、GlassButton 与 Element Plus。桌面左侧单据、右侧操作，各自滚动；页头与底部操作保持可见。窄屏上下排列、正文自然滚动。单据本身承担视觉重心，不添加图片或装饰。

- 页头集中客户、编号、版本、状态和当前总额；当前、历史、提案仍分别展示，历史证据提示保留。
- 商品改为可排序表格，数值对齐；排序只改变显示顺序，不修改商品、金额、计算或请求。
- 运输/业务员联系信息、商品来源 ID、客户归属 ID 改为按需展开。付款、费用、收货与备注仍完整保留。
- 减法：移除展开显示的技术 ID 及重复字段标签；将分散的操作解释合并为一段。保留版本、权限、结果未决和作废后果等必要提示。
- 沿用弹窗出入、标签切换、按钮反馈与下载 loading，不增加装饰动画。视频和标签切换 trace 已生成；未单独作录屏正常速度播放审查，不把静态截图当作动效验收。
